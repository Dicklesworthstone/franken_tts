## Load-bearing census results

- Text embedding: `talker.model.text_embedding.weight`, BF16 `[151936, 2048]`, 622,329,856 B.
- Text projection: BF16 `linear_fc1` `[2048, 2048]` then `[2048]` bias; `linear_fc2` `[1024, 2048]`
  then `[1024]` bias.
- Talker primary embedding and head: BF16 `[3072, 1024]` each. The primary vocabulary is 3,072;
  residual heads are not interchangeable with it.
- Microdecoder: five BF16 layers, plus exactly 15 BF16 depth embeddings and 15 BF16 heads. Every
  per-depth table/head is `[2048, 1024]`; neither is shared across depth.
- Speech tokenizer: 496 F32 tensors. It contains 271 decoder and 225 encoder tensors; its F32 RVQ
  codebooks remain high precision.
- Speaker encoder tensors are BF16 and included in the main checkpoint manifest.

## Microdecoder hot-pack accounting

The invariant one-read **traffic floor** is **110,100,480 B (110.1 MB decimal)**:

| Component | Q8 bytes | Role |
|---|---:|---|
| Five-layer microdecoder body | 78,643,200 | reread by the sequential 15-step loop |
| Fifteen `[2048,1024]` depth heads | 31,457,280 | one selected head per depth |
| **Traffic floor** | **110,100,480** | target for OQ-18 DRAM-bytes/frame measurement |

The 15 depth embedding tables are a further 31,457,280 B of Q8 **pack footprint**, but each frame
gathers only one 1,024-byte row from each (15,360 B/frame). They must be placed with the hot pack but
must not be added to the 110.1 MB one-read traffic floor. The shared talker `[3072,1024]` codec
embedding supplies code 0 in the 16-position microdecoder sequence and is likewise an explicit shared
dependency, not a duplicate per-depth table.
